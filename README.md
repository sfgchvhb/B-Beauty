# B-BEAUTY — 부산 코스메틱 연합 플랫폼

부산 화장품 브랜드 5개사(아마란스·크레이지앤트·엘다라·더블리·유엔비)의 연합 플랫폼 사이트입니다.
제품을 소개하고 구매는 각 브랜드 공식몰로 연결합니다. 자체 결제는 없습니다.
한국어·영어·중국어 3개 언어를 지원합니다.

의존성 없는 **순수 HTML/CSS/JS**로 만들어져 있습니다. React·Tailwind·빌드 도구를 쓰지 않습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 사이트 본체. 이미지·데이터가 모두 들어 있는 단일 파일. **배포는 이 파일** |
| `index-미리보기.html` | 사진만 줄인 경량본(약 0.7MB). 내용은 동일. 미리보기 전용 |
| `build.py` | `src/` 를 묶어 위 두 파일을 만드는 스크립트 |
| `src/` | 실제 소스. 여기를 고치고 `build.py` 를 돌립니다 |

제품·가격 정보는 각 브랜드 공식몰/스토어 캡처를 기준으로 사이트에 직접 넣어 둡니다.
외부 사이트를 실시간으로 읽어오지 않으므로 서버·API·네트워크 설정이 필요 없습니다.

## 1. 수정하고 다시 빌드하기

```bash
python3 build.py        # index.html 재생성
```

이미지를 base64 로 파일에 내장하므로 `index.html` 하나만 있으면 인터넷 없이도 열립니다.

## 2. 배포

### Cloudflare Pages (권장 · 무료)

1. GitHub 에 이 폴더를 올립니다.
2. Cloudflare 대시보드 → Workers & Pages → Create → Pages → Connect to Git
3. 빌드 설정은 비워 둡니다 (정적 파일이라 빌드가 필요 없습니다).
   - Build command: *(비움)*
   - Build output directory: `/`
4. 배포 후 Custom domains 에서 보유하신 도메인을 연결합니다. SSL 은 자동 발급됩니다.

### 그 외

- **Netlify / Vercel** — 폴더를 화면에 끌어다 놓으면 배포됩니다.
- **GitHub Pages** — Settings → Pages → Branch 지정.
- **직접 열기** — `index.html` 을 더블클릭하면 그대로 열립니다.
  로컬에서 서버로 확인하려면:

  ```bash
  python3 -m http.server 8000
  # http://localhost:8000 접속
  ```

## 3. 제품 정보 갱신 방법

공식몰에 새 제품이 올라오거나 가격이 바뀌면 다음 순서로 반영합니다.

1. 공식몰/스마트스토어에서 제품 정보와 사진을 확인합니다.
2. 사진은 `src/images/` 에 넣습니다.
3. `src/data/dataset.json` 의 해당 브랜드 항목을 고칩니다.
   `KR` · `EN` · `CN` 세 곳을 모두 맞춰야 언어 전환 시 어긋나지 않습니다.
4. `python3 build.py` 로 다시 빌드합니다.

공지·이벤트는 `src/data/notices.json`(+ `notices_tr.json`),
커뮤니티 글은 `src/data/posts.json` 에서 고칩니다.

## 커뮤니티 서버 연결 (Vercel)

지금 상태에서 커뮤니티 글은 **글을 쓴 사람의 브라우저에만** 저장됩니다.
아래 4단계를 마치면 **모든 방문자가 같은 글을 보게** 되고,
비밀번호 확인도 서버가 맡아 **개발자도구로 우회할 수 없게** 됩니다.

### 1단계 — Supabase 에서 표 만들기 (5분, 무료)

1. supabase.com 가입 → 새 프로젝트 만들기
2. 왼쪽 **SQL Editor** 에서 아래를 붙여 넣고 실행합니다.

```sql
create table community_posts (
  id          text primary key,
  date        text,
  pw_hash     text not null,
  data        jsonb not null,
  created_at  timestamptz default now()
);

-- 관리자가 올리는 이벤트·공지
create table admin_board (
  id          text primary key,
  kind        text not null,          -- 'event' 또는 'notice'
  data        jsonb not null,
  created_at  timestamptz default now()
);
```

3. **Settings → API** 에서 두 값을 복사해 둡니다.
   - `Project URL`
   - `service_role` 키 (⚠ **절대 외부에 공개하지 마세요.** 화면에 넣는 값이 아닙니다)

### 2단계 — Vercel 에 환경 변수 넣기

Vercel 프로젝트 → **Settings → Environment Variables** 에서 네 개를 넣습니다.

| 이름 | 값 |
|---|---|
| `SUPABASE_URL` | 1단계의 Project URL |
| `SUPABASE_SERVICE_KEY` | 1단계의 service_role 키 |
| `ADMIN_PW` | 관리자 마스터 비밀번호 (원하는 값) |
| `PW_SALT` | 아무 긴 문자열 (예: `bb-2026-x9f2k7q1`) |

### 3단계 — 화면이 서버를 보도록 한 줄 고치기

`src/app.js` 에서 다음 한 줄을 고칩니다.

```js
var COMMUNITY_API = '/api/posts';
```

고친 뒤 `python3 build.py` 로 다시 만듭니다.

### 4단계 — 올리기

⚠ **깃허브에 올릴 때는 「폴더 안의 내용」을 올려야 합니다.**
압축을 풀면 `b-beauty` 폴더가 생기는데, **그 폴더째로 올리면 안 됩니다.**
저장소 맨 위에 `index.html` · `api` · `vercel.json` 이 바로 보여야 합니다.

```
내저장소/
├── index.html      ← 이 자리에 있어야 한다
├── api/
│   └── posts.js
├── vercel.json
└── src/
```

⚠ **`vercel.json` 에 `functions` 설정을 넣지 마세요.**
`"functions": { "api/posts.js": ... }` 를 넣으면, 경로가 조금만 어긋나도
**「doesn't match any Serverless Functions」 오류로 빌드가 실패**합니다.
Vercel 은 `api/` 폴더를 자동으로 알아보므로 이 설정이 필요 없습니다.
(2026-09-01 에 이 문제로 배포가 실패해 설정을 뺐습니다.)


`index.html` 과 함께 **`api/posts.js` 와 `vercel.json` 도 같이** 올립니다.
Vercel 이 `api/` 폴더를 알아서 서버 기능으로 인식합니다.

---

### 이렇게 하면 달라지는 것

| | 지금 | 서버 연결 후 |
|---|---|---|
| 내 글이 남에게 | 안 보임 | **보임** |
| 다른 기기에서 | 안 보임 | **보임** |
| 비밀번호 확인 | 브라우저 (우회 가능) | **서버 (우회 불가)** |
| 관리자 모드 | 브라우저에서 조작 가능 | **서버가 확인** |

### 알아 두실 점

- **서버가 응답하지 않아도 글은 사라지지 않습니다.** 화면에 그대로 남고 브라우저에도
  저장되며, 「서버 저장에 실패했습니다」 안내가 뜹니다.
- 서버를 연결하면 **비밀번호는 서버만 보관합니다.** 브라우저에는 남지 않습니다.
- **사진은 글 안에 담겨 함께 전송됩니다.** 한 장당 최대 약 300KB 이므로,
  Supabase 무료 구간(500MB)이면 글 수천 개는 충분합니다.
- 스팸을 막는 장치는 없습니다. 공개 운영 시 `api/posts.js` 에 글쓰기 횟수 제한을
  넣거나, Supabase 쪽에서 차단 규칙을 두시길 권합니다.

## 커뮤니티 글 비밀번호 · 관리자

## 이벤트·공지 올리기 (관리자 전용)

**관리자 로그인을 해야 작성 버튼이 보입니다.**
로그인은 **푸터 오른쪽 아래**의 「관리자」 버튼에서 합니다 (어느 화면에서든 보입니다).

로그인하면 **이벤트 / 공지사항** 화면 위에 「＋ 작성」 버튼이 나타납니다.

### 쓸 수 있는 것

| 기능 | 설명 |
|---|---|
| **글자 색** | 8가지 중에서 고릅니다 |
| **글꼴** | 기본 · 명조 · 고딕 · 고정폭 |
| **글자 크기** | 아주 작게 ~ 아주 크게 (5단계) |
| 굵게 · 기울임 · 밑줄 · 목록 | 선택한 글자에 적용됩니다 |
| **사진** | 여러 장 한 번에. 긴 변 1400px 로 줄여 넣습니다 |
| **영상** | 유튜브 주소 또는 영상 파일 (12MB 이하) |

⚠ **영상은 유튜브 주소를 권합니다.**

**서버를 연결하면 영상 파일은 3MB 까지만 올라갑니다.** Vercel 서버 기능이 한 번에
받을 수 있는 크기가 4.5MB 로 정해져 있는데, 파일을 글자로 바꿔 담으면 약 1.37배로
늘어나기 때문입니다. 넘으면 **이 기기에만 저장되고** 안내가 뜹니다.

사진도 여러 장 넣으면 합계가 커집니다. 한 장당 약 300KB 이므로 10장 정도가 한계입니다.
**긴 영상이나 사진이 많은 글은 유튜브 주소를 쓰시는 편이 안전합니다.**

### 올린 뒤

- 이벤트는 카드로, 공지는 목록으로 바로 나타납니다.
- **작성 시각이 초 단위까지** 함께 남습니다.
- 관리자로 로그인한 상태에서 그 글을 열면 **수정·삭제 버튼**이 보입니다.
- 욕설·혐오 표현 검사는 관리자 글에도 똑같이 적용됩니다.

⚠ 서버를 연결하지 않으면 **올린 사람의 브라우저에만** 저장됩니다.
방문자에게 보이게 하려면 위 「커뮤니티 서버 연결」을 먼저 마쳐야 합니다
(`admin_board` 표를 함께 만드는 SQL이 들어 있습니다).

### 욕설·혐오 표현 거르기

글과 댓글을 올릴 때 **닉네임·제목·본문을 모두 확인**해, 욕설이나 혐오 표현이 있으면
등록되지 않고 어떤 표현이 걸렸는지 알려 줍니다.

- 「ㅅ.발」 「시 발」 처럼 **기호나 띄어쓰기로 우회하는 것도 잡습니다.**
- 그래도 들어온 말(서버에서 받아 온 글, 예전 글)은 **화면에 보일 때 별표로 가립니다.**
  `시발` → `시*`, `fuck` → `f***`

**낱말 목록은 `src/data/badwords.json` 에 있습니다.** 운영하면서 채워 나가시면 됩니다.

```json
{
  "words": ["막을 낱말들"],
  "allow": ["잘못 걸리는 정상 낱말들"]
}
```

⚠ `allow` 가 중요합니다. 예를 들어 「시발점」 「십자가」 「새끼손가락」 은
막을 낱말을 품고 있지만 정상 표현이라 여기에 넣어 두었습니다.
새 낱말을 추가한 뒤에는 **정상 문장이 잘못 막히지 않는지** 꼭 확인하세요.

고친 뒤 `python3 build.py` 로 다시 만듭니다.

### 작성 시각

글과 댓글에 **날짜와 시:분:초**가 함께 남습니다 (`2026-08-31 15:56:31`).
예전에 날짜만 있던 글도 그대로 보입니다.

### 수정·삭제 메뉴

글과 댓글 오른쪽 위의 **점 세 개(⋮)** 를 누르면 수정·삭제 메뉴가 나옵니다.

- **글** — 목록에서 바로 됩니다. 상세로 들어갈 필요가 없습니다.
- **댓글** — 그 댓글 자리에서 바로 됩니다.

댓글도 글과 마찬가지로 **쓸 때 숫자 4자리 비밀번호**를 정하고,
수정·삭제할 때 그 비밀번호를 넣어야 합니다.

### 엔터로 확인

비밀번호를 넣고 **엔터를 누르면 바로 확인**됩니다. 창이 열리면 커서도 자동으로 놓입니다.
- 관리자 로그인
- 글쓰기 · 댓글 등록
- 글/댓글 수정·삭제 시 비밀번호 확인

### 글쓴이 비밀번호

글을 쓸 때 **닉네임과 숫자 4자리 비밀번호**를 입력합니다.
그 글을 **수정하거나 지울 때 같은 비밀번호**를 넣어야 합니다.

- 비밀번호는 **그대로 저장되지 않습니다.** 되돌릴 수 없는 값으로 바꿔 저장하며,
  글마다 다른 값을 섞기 때문에 같은 비밀번호라도 저장값이 서로 다릅니다.
- **잊으면 되찾을 수 없습니다.** 그때는 관리자가 지워야 합니다.

### 관리자

**푸터 오른쪽 아래**의 「관리자」 버튼을 누르고 마스터 비밀번호를 넣으면,
**모든 글을 비밀번호 없이** 수정·삭제할 수 있습니다.

기본 마스터 비밀번호는 **`bbeauty2026!`** 입니다. **운영 전에 반드시 바꾸세요.**

바꾸는 방법:

1. 사이트를 열고 브라우저 개발자도구 콘솔에서 다음을 실행합니다.
   ```js
   await BB.makeAdminHash('새로운비밀번호')
   ```
2. 화면에 나온 값을 `src/app.js` 의 `ADMIN_HASHES` 첫 줄에 붙여 넣습니다.
3. `python3 build.py` 로 다시 만듭니다.

⚠ `ADMIN_HASHES` 에 값이 두 개인 이유: 보안 연결(https)이 아니거나 옛 브라우저에서는
계산 방식이 달라집니다. **두 환경에서 각각 값을 만들어 두 줄 모두 채워야** 어디서든 로그인됩니다.

⚠ **이 방식은 화면을 지키는 수준입니다.** 브라우저에서 도는 코드라, 마음먹으면 우회할 수 있습니다.
정말 중요한 글을 다루신다면 **서버에서 비밀번호를 확인**하도록 만들어야 합니다
(위 「커뮤니티 서버 연결」 참고).

## 방문 통계 (구글 애널리틱스 4)

### 켜는 방법

1. 구글 애널리틱스에서 속성을 만들고 **측정 ID**(`G-XXXXXXXXXX`)를 확인합니다.
   (관리 → 데이터 스트림 → 웹)
2. `build.py` 위쪽의 한 줄에 넣습니다.
   ```python
   GA4_ID = 'G-XXXXXXXXXX'
   ```
3. `python3 build.py` 로 다시 만든 뒤 올립니다.

비워 두면 아무 코드도 들어가지 않습니다.

**IP 익명 처리를 켜 두었습니다** (`anonymize_ip: true`). 개인정보처리방침에 밝힌 내용과 맞춥니다.

### 쿠키 동의 배너

**동의를 받기 전에는 GA4 가 아예 실행되지 않습니다.** 구글 서버에 연결조차 하지 않습니다.
유럽(GDPR·ePrivacy)은 **쿠키를 심기 전에** 동의를 받아야 하므로 이렇게 만들었습니다.

- 처음 방문하면 화면 아래에 배너가 뜹니다 (4개 언어)
- **동의** → 그때부터 GA4 시작 / **거부** → 실행 안 함 (이용 제한 없음)
- 한 번 고르면 기억해 다시 묻지 않습니다
- **푸터의 「쿠키 설정」** 으로 언제든 다시 고를 수 있습니다 (유럽은 철회권이 필요합니다)

⚠ **배너 문구를 고칠 때 주의하세요.** 「방문자 수 집계」 목적만 밝히고 있습니다.
나중에 광고 기능을 켜신다면 그 목적도 배너와 처리방침에 함께 적어야 합니다.
